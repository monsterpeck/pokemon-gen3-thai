# Pokémon Emerald Thai Localization Policy

เอกสารนี้เป็นมาตรฐานหลักสำหรับงานแปลภาษาไทยทั้งหมดของโปรเจกต์

## นโยบายหลัก

| หมวด | แนวทาง |
|---|---|
| ชื่อโปเกมอน | ใช้ภาษาไทยถอดเสียงจากชื่อญี่ปุ่นตามบัญชีอ้างอิงของโปรเจกต์ |
| ชื่อท่า | คงชื่อภาษาอังกฤษเดิม |
| ชื่อไอเทม | คงชื่อภาษาอังกฤษเดิม |
| คำอธิบายท่า | แปลเป็นภาษาไทย |
| คำอธิบายไอเทม | แปลเป็นภาษาไทย |
| เมนูและข้อความระบบ | แปลเป็นภาษาไทย |
| เนื้อเรื่องและบทสนทนา | แปลเป็นภาษาไทย |

## กฎการแปล

1. ห้ามแปลหรือถอดเสียงชื่อท่าเป็นภาษาไทย
2. ห้ามแปลหรือถอดเสียงชื่อไอเทมเป็นภาษาไทย
3. ชื่อท่าและชื่อไอเทมต้องคงรูปแบบภาษาอังกฤษของเกมต้นฉบับ
4. ชื่อโปเกมอนต้องอ้างอิงจากบัญชีชื่อไทยจากชื่อญี่ปุ่นของโปรเจกต์
5. ห้ามสร้างหรือเปลี่ยนการสะกดชื่อโปเกมอนโดยไม่มีข้อมูลอ้างอิง
6. คำอธิบายท่าและไอเทมต้องแปลครบความหมายและอ่านเป็นธรรมชาติ
7. คงคำย่อมาตรฐาน เช่น HP, PP, EXP, TM และ HM
8. เมนู ข้อความระบบ เนื้อเรื่อง และบทสนทนาต้องแปลเป็นภาษาไทย
9. ทุกชุดคำแปลต้องผ่าน Coverage, Build, Visual และ Context QA

## ตัวอย่าง

ชื่อท่า:
EMBER

คำอธิบายท่า:
โจมตีด้วยเปลวไฟขนาดเล็ก
อาจทำให้เป้าหมายติดสถานะไหม้

ชื่อไอเทม:
RARE CANDY

คำอธิบายไอเทม:
เพิ่มเลเวลของโปเกมอนขึ้น 1 ระดับ

ข้อความระบบ:
อาชาโมะเรียนรู้ EMBER แล้ว!
ได้รับ POTION!

## สถานะ Inventory

- keep_english — ชื่อท่าหรือชื่อไอเทมที่ต้องคงภาษาอังกฤษ
- pending — ยังไม่ได้แปล
- translated_pending_qa — แปลแล้วและรอการตรวจ
- proof_passed — ผ่านการตรวจใน ROM แล้ว
